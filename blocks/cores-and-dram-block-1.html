About the model

  • Each core repeats one loop: compute briefly, request data from DRAM, wait for it to come back.
  • DRAM is six lanes. A lane is held for the full round trip, so bandwidth is lanes divided by latency.
  • The dots are a live run. The bars and the curve show the same model's steady state.
